Server Groups

Servers can be categorized into "Groups"

  • Servers in the same group share the same base server configuration and same leaderboards.
  • Servers in separate groups have different and incompatible configuration and have different leaderboards.

There are 6 Main Groups: G1, G2, G3, G4, G5, and G5

Commonality

If two servers are in the same Main Group, the two servers will share the same:

  • Base Server Configuration
  • Advanced and Perfect Dimensional Tunnel
  • Dimensional Tunnel Cross-Server Leaderboard
  • Lave Cave Leaderboard
  • Evil Spirit Invasion Leaderboard
  • Lava Haka Leaderboard
  • Ultimate Power Leaderboard
  • Ultimate Hunting Leaderboard
  • Wishing Pool in special events
  • Cross-Server Leaderboard in special events
