Server Groups

When a batch of new servers open, they may get server configurations that are different from servers before them. When enough number of these servers are opened, they would eventually form a new Server Group. Currently, there are 6 Main Groups: G1, G2, G3, G4, G5, and G6

Note that Group and Season are independent of one another (Season is not a sub-group of Group). Two servers can be in the same Group but different Seasons. Conversely, two servers can be in the same Season but in different Groups. See Server Differences.
