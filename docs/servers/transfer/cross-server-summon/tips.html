Alliance Cross-Server Summon Tips

Tips

  • If possible, use Server Transfer instead of Cross-Server Summon

  • Check the status of the server on the Server Transfer listings. If you cannot find the server in the listing, or if the server is listed as Not active enough in the Can't transfer tab, the server is probably very inactive.

  • Use Cross-Server Summon as your exit plan. If you made a mistake with a server transfer, use Cross-Server Summon to exit the server.

  • Remember that some event progresses will reset after a transfer.
