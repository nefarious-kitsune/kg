Posting Cross-Server Summon

At the end of each season, there is a 6-Day Alliance Cross-Server Summon event. During the event, alliances can post summons to recruit players from other servers.

Eligibility

  • Each server has a certain quota depending on the activity level of the server. If the server is full, the quota would be zero (0).

  • The quota is shared by all alliances on the server. If the quota is exhausted, no player can join via Alliance Cross-Server Summon.

  • An alliance must have at least 10 open spots to post a summon. An alliance cannot use Cross-Server Summon if the alliance has applied for server transfer.

Posting

  • An R4/R5 of an eligible alliance can post a Cross-Server Summon.

  • When posting a summon, the R4/R5 can select Alliance Tag, Activity Time, and Minimum Power

  • Alliance Tag states if the alliance is for fighting (Conquer the World), casual play (Active Growth), or farming (Peaceful Development)

  • Activity Time states when if the alliance normally does its events: UTC 0100 ~ 0700, UTC 0700 ~ 1300, UTC 1300 ~ 1900, or UTC 1900 ~ 0100

  • After a summon is posted, the summon can be modified but not cancelled.

Reviewing

R4 and R5 can review application and choose to accept or deny players. When a player is accepted, the player is immediately transferred to the alliance.

Visibility

  • R4 and R5 can see their alliance's own summon.

  • R1, R2, and R3 cannot see their alliance's summon.

  • Players cannot see the summon posted by other alliances on the same server.
