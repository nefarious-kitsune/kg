Cross-Server Summon

Alliance Cross-Server Summon is a 5-day event that happens on Week 4 of each KvK Season. During the event, alliances can post Beckons to recruit players from other servers.

Visibility

  • R4 and R5 can see their alliance's own Beckon.

  • R1, R2, and R3 cannot see their alliance's Beckon.

  • Players cannot see the Beckon posted by other alliances on the same server.
