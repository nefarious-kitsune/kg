Text Formatting

You can format Mail and Alliance Notice messages with HTML-like tags.

Basics

Remember to set <b>Auto Rally</b> on. Remember to set Auto Rally on.
Remember to set <i>Auto Rally</i> on. Remember to set Auto Rally on.
Remember to set <size=60>Auto Rally</size> on. Remember to set Auto Rally on.
Remember to set <color=#B00>Auto Rally</color> on. Remember to set Auto Rally on.

Formatting tags must be closed properly. For example, <color=red><size=40>text</color></size> will not display properly.
