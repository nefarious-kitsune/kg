Custom Function - Dragonden Emblem Upgrades

Reference custom function (App Script) for calculating Dragonden Emblem upgrades.

Installing the Function

  1. Open dragon-upgrade.js and copy the content.
  2. Select the menu item Extensions > Apps Script.
  3. Delete any code in the script editor. Copy and paste the code into the script editor.
  4. At the top, click Save

See Custom Functions in Google Sheets

Syntax

The general syntax for the function is

calculateDragonUpgrade(inventory, exchange, emblems)

  • inventory - Current inventory of Dragon Runes ([rare, excellent, perfect, epic, free-pick])
  • exchange - Exchange settings for Free-Pick Dragon Runes ([rare, excellent, perfect, epic])
  • emblems - Current levels of Dragonden Emblems ([bronze, silver, golden, legendary])

Output

The function returns a 2-dimensional array

  • Row 1 is a list of inventory after upgrades ([rare, excellent, perfect, epic, free-pick])
  • Row 2 is a list of Emblem levels after upgrades ([bronze, silver, golden, legendary])
  • Row 3 is a list of Dragon Runes consumed after upgrades ([rare, excellent, perfect, epic])

Sample Usage

See Sample Google Sheets File

Sample code when input values are continuous ranges

calculateDragonUpgrade(C7:G7, C11:G11, C15:F15)

If input values are discontinuous, use brackets {} to collect them into arrays

calculateDragonUpgrade(
 {F6, F8, I6, I8, F11},
 C11:G11,
 {F19, F21, I19, I21}
