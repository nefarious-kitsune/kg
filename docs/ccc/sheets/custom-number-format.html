Customer Number Formats

Sometimes you want to input large numbers and have Google Sheet (or Excel) automatically displays them in easy-to-understand format. For example, you may want to enter a number like 196876526123 and have it displayed as 196.88B.

You can use custom number formats to help you with that. See Sample Google Sheets File

Example: Number in Trillions

To display large numbers in the Trillions (T) and Billions (B) range, use the custom number format [>999999999999] #.00,,,,"T";[>999999999] #,,,"B";General

Raw Displayed
96625612434789 96.63T
753256980000 753B

Example: Number in Billions

To display large numbers in the Billions (B) and Millions (M) range, use the custom number format [>999999999] #.00,,,"B";[>999999] #,,"M";General

Raw Displayed
196876526123 196.88B
756560077 757M

Example: Sum It Up

Using a custom number format is especially useful if you want to enter many numbers and sum them up to a much larger number.

Example: Summing Numbers
Raw Displayed
Item 1 368765000 369M
Item 2 482236000 482M
Item 3 856655000 857M
Total 1707656000 1.71B
