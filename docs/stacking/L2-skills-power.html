Layer-2 Skills Power

When a hero in a Troops March has applicable bonus unit-power skill (e.g. Guerrilla Master), the Troops Unit gain gains Bonds Power.

The Skills Power depends on total percentage of applicable skills, Unit Base Power, and Unit Evolution Power.

Calculation

Skills Power = ( Unit Base Power + Unit Evol. Power ) × Unit-Power bonus
