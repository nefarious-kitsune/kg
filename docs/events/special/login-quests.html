    • Some special events (e.g. Reserve Winter Grain and Knight Tournament) have 5-Day Login Quests.

    On each of the first 5 days, a new set of quests will become visible. The quests can be completed in any order. For example, a Day-5 quest can be completed on day 1, and a Day-1 quest can be completed on the last day.

    Completing all quests will grant the Lord 1400 Tokens.

    Day 1

    QuestTokens

    Spend 10,000 Gem(s) 20
    Upgrade any Hero 100 level(s) 10
    Use 400 Action Point(s) 20
