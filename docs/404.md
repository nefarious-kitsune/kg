# Under Maintenance.

Miku's Shrine is currently offline.

The source code is still publicly available on GitHub,
and you can host the site locally on your desktop computer:

Assuming you have
[git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) and
[node.js](https://nodejs.org/en/download/prebuilt-installer) installed

1. Clone the source code: `git clone https://github.com/nefarious-kitsune/kg`
2. Switch to the "web" branch: `git checkout web`
3. Install a server application: `npm install http-server -g`
4. Run the site on your local Desktop: `http-server -o ./docs/`
