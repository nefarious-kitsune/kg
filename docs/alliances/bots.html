    • If an alliance is set to Everyone can join and has spaces for more members, bots will randomly appear on the map. Bots can help alliance members fill Titan rallies and bots will also start Titan rallies. Bots always have the same power and are always under shields.

    Adding/Removing Bots

    Bots can be a nuisance during Evil Spirit Invasion or Lava Haka summons because they can pull troops away from castles with their Titan rallies.

    To remove bots, set the alliance's Join Restriction to Application required, then manually remove the bots from the alliance.

    To add bots back, set the alliance's Join Restriction back to Everyone can join, and the bots should join momentarily

    Spawn Locations

    The Spawning locations of the bots are random and cannot be controlled. If the alliance has a Central Fortress, bots will always appear in that vicinity.
