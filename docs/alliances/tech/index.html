Alliance Tech

Alliance Tech is very important in building a strong alliance. Alliance Tech provides buffs such as marching speed, gold gathering, and damage recovery.

If you lose a territory (e.g. from territory war or server transfer), you will lose the buffs from previously claimed altars. However, you will never lose the Alliance Tech (even if you lost the Central Fortress!)

Tips for R5 & R4

If you are an R5 or R4, you can send out regular reminder mail and ask fellow Alliance Members to do Tech donation. Mark the Tech you want to focus on with a star so that the Tech can complete faster.
