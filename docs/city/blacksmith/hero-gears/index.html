    Hero Gears (Weapons) provide the equipped Heroes bonus powers that are percentages of the Blacksmith Base Power…

    Acquiring Hero Gears

    A Hero Gear (Weapon) can be purchased or crafted from 100 Forge Blueprints of the same tier. See Acquiring Hero Gears.

    Equipping/Dismantling

    Each Hero can be equipped with maximum 1 Hero Gear which provides Hero Gear Power that is a percentage of the Blacksmith Base Power.

    Unused Hero Gear can be dismantled to recover Forge Blueprints, Elemental Vial, and Blood of Titan used.
