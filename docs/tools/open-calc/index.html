Open KG Calculator

Open KG Calculator is a Google Sheets-based calculator for calculating upgrades and Mightiest Kingdom points. The calculator is in early development and not ready for uses by players.

The tool is built from scratch and makes heavy uses of advanced features such as arrays, array formulas, named functions, and named ranges.

The tool is open source (public domain, actually) and heavily documented. You are free to modify it and distribute your own derivative versions.
