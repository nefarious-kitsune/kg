Forge Blueprint

  • Use
  • Acquire
  • Exchange

    • Use

    Forge Blueprints can be used to craft Hero Gear(s).

    Each Hero Gear requires 100 Forge Blueprints of the same tier.

    Forge Blueprints cannot be merged to create a higher-tier Forge Blueprints.

    Acquire

    Forge Blueprints can be acquired in various ways:

    • Mightiest Kingdom ranking/phase rewards
    • Burning Expedition personal ranking rewards
    • Discount Pass
    • Alliance Treasure
    • Dismantling a Hero Gear

    Exchange

    Unused Forge Blueprints can be exchanged for Elemental Vial. at the Exchange Shop.

    ×1 T2 Forge Blueprint » ×1 Elemental Vial
    ×1 T3 Forge Blueprint » ×4 Elemental Vials
    ×1 T4 Forge Blueprint » ×20 Elemental Vials
    ×1 T5 Forge Blueprint » ×100 Elemental Vials
