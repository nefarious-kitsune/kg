Example: Number in Trillions

To display large numbers in the Trillions (T) and Billions (B) range, use the custom number format [>999999999999] #.00,,,,"T";[>999999999] #,,,"B";General

Raw Displayed

753256980000 753B

Example: Number in Billions

To display large numbers in the Billions (B) and Millions (M) range, use the custom number format [>999999999] #.00,,,"B";[>999999] #,,"M";General

Raw Displayed
196876526123 196.88B
756560077 757M
