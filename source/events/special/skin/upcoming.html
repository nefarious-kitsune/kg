Every 4-weeks, the game has a 8-day Holiday Event that starts on the last day of the season. The event is generally pay-to-play.

Event Rewards

In the holiday special event, Lords have a chance to obtain the following rewards.

  • SSR Hero Cards
  • Avatar Frame
  • Castle Skin
  • Limited Castle Skin

Event Format

Each holiday special event generally follows the same format:

Quest

Collect Lv. 1 Tokens by completing quests such as defeating Titans and monsters.

Mini Game

Consume Lv. 1 Tokens to play a mini-game such as pinball or Blackjack.

Event Pass

Consume game points earned from the mini-game to unlock Event Pass rewards:

  • Free-tier: Lv. 3 Tokens
  • Paid-tier: Lv. 3 Tokens and a permanent Avatar Frame
Lucky Draw

Consume Lv. 3 Tokens (collected from Event Pass, Wishing Pool, and event pack purchases) to draw rewards from the event treasure vault. Tap the upper-right button to switch between the Normal Mode and the Crazy Mode.

Wishing Pool

Consume Gems to make a wish at the Wishing Pool and receive rewards. The first 100 wishes made daily will grant a Lv. 3 Token.

Half of all gems used will be added to the grand prize, and one lucky Lord will be randomly selected to win the grand prize.
