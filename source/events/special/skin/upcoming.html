Every 4-weeks, the game has a 8-day Holiday Event that starts on the last day of the season. The event is generally pay-to-play.

Event Rewards

In the holiday special event, Lords have a chance to obtain the following rewards.

  • SSR Hero Cards
  • Avatar Frame
  • Castle Skin
  • Limited Castle Skin

Event Format

Each holiday special event generally follows the same format:

Quest

Complete quests such as defeating Titans and monsters to collect Lv. 1 Token.

Mini Game

Lords can use collected Lv. 1 Tokens to play a mini game such as pinball or Blackjack and collect Lv. 2 Tokens

Event Pass

Lords can consume Lv. 2 Tokens to unlock Event Pass rewards. Free tier rewards include Lv. 3 Tokens. Paid-tier rewards include more Lv. 3 Tokens and a permanent Avatar Frame.

Lucky Draw

Lords can consume Lv. 3 Tokens (collected from Event Pass, Gem Wishing Pool, and additional purchases) to draw SSR Hero Cards and other rewards. Lords can draw in either the Normal Mode or the Crazy Mode.

Gem Wishing Pool

Lords can use Gem to make a wish at the Gem Wishing Pool.

Half of all gems used will be added to the prize pool; and every once in a while, one lucky person can win all the gems in the prize pool.

The first 100 wishes made daily will grant a Lv. 3 Tokens.
