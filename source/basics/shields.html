Auto Shields

In some circumstances, castles may get automatic shields:

  • In the event of a system maintenance, castles not in Scorched Land get automatic shields. The shield is removed as soon as the character logs in. If the character stays inactive, the shield is removed in <24 hours.
  • If a castle is still in Broken Land when Burning Expedition ends, and the castle gets an automatic shield that expires in 72 hours.
  • When a character transfers server (via personal transfer or Cross-Server Summon), the castle gets an automatic shield that expires in 72 hours.
  • Bots are always shielded.
  • During the first few weeks after a server opens, low-level castles are under shields. The shields are removed after the server has its first Cross-Server Invasion..

Automatic shields do not stack.
