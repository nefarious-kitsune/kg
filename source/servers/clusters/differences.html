C200s

Differences compared to C100s:

  • Standardized layout of Dragon Nests (variant A and B)
  • Reduced unit evolution upgrade cost and reduced unit powers
  • Beginner event Imperial Treasure I, II, III, and IV give 500 VIP points
  • Castle level after 200 are not caped by stage levels

C300s

Differences compared to C200s:

  • Standardized layout of Dragon Nests (variant B)
  • Unlock requirements for Alliance, Map, Academy, etc. adjusted
  • Unlock requirements for Dragon and Dragon Armor adjusted
  • Quests in Dragon Quests adjusted
  • Quests in Imperial Treasure I adjusted. The event gives 225 VIP points
  • Beginner event Imperial Treasure II, III, and IV removed
  • Beginner event Crazy Harold removed
  • Beginner event Beginner Gift removed
  • Server welcoming event Personal Championship added to server 1276+
  • Gold costs for some Academy Tech upgrades removed
  • Territory Protection added to Alliance Tech
  • Castle level after 15 are not caped by stage levels
  • Some castle skins removed (e.g. Halloween, Valentine, Easter)

X350s

X350s is a micro cluster with some experimental features.

Differences compared to C300s:

  • Beginner event Imperial Treasure I gives 0 VIP points
  • Beginner event Crazy Harold re-introduced
  • (X350-only) Heroes have multi-color star promotion
  • (X350-only) Heroes in tower defense and heroes in world marches can be different
  • (X350-only) Different user interface for heroes
  • (X350-only) Tower Defense has 4 hero towers and 4 unit towers
  • Gem quests added to Bounty Hall
  • Some castle skins removed (e.g. Elf, Goblin Lab)

C400s

Differences compared to C300s:

  • Beginner event Imperial Treasure I gives 60 VIP points
  • Beginner event Crazy Harold re-introduced
  • Gem quests added to Bounty Hall
  • Some castle skins removed (e.g. Elf, Goblin Lab)
