In Kingdom Guard, servers are grouped into various groups.

Official Grouping

Officially, servers are grouped into four clusters. The cluster designations are used to help players with server recruitment and are unrelated to the actual game mechanics.

  • S1: 9001 ~ S024
  • S2: 401 ~ 1150, 2002
  • S3: 1151 ~ 1598
  • S4: 1599 ~

Unofficial Grouping

The following is an unofficial description of the server clusters. A different naming scheme is used in order to captivate the complexity of the actual mechanism.

Servers are grouped into several Main Clusters, which are further divided into Sub Clusters. In general, servers in the Main Cluster play the same system.

Cross-Server Matching

The following are generally based on Main Clusters

  • Dimensional Tunnel
  • Dimensional Tunnel Cross-Server Leaderboard
  • Lave Cave Leaderboard
  • Evil Spirit Invasion Leaderboard
  • Ultimate Power Leaderboard
  • Ultimate Hunting Leaderboard
  • Wishing Pool in special events
  • Cross-Server Leaderboard in special events

The following are generally based on Sub Clusters

  • Releases of new heroes and tiers
  • Cross-Server Invasion matching
  • Mightiest Kingdom matching
  • Burning Expedition matching
  • Personal Server transfer and cross-server summoning
  • Alliance Cross-Server Summon

Systems

System Changes
C100s Original system
C200s
  • Standardized World Map (variant A and B)
  • Reduced unit evolution upgrade cost and reduced unit powers
  • Beginner event Imperial Treasure I, II, III, and IV give 500 VIP points
  • Castle level after 200 are not caped by stage levels
C300s
  • World Map variant B
  • Unlock requirements for Alliance, Map, Academy, etc. adjusted
  • Unlock requirements for Dragon and Dragon Armor adjusted
  • Beginner event Imperial Treasure I gives 225 VIP points
  • Beginner event Imperial Treasure II, III, and IV removed
  • Beginner event Crazy Harold removed
  • Beginner event Beginner Gift removed
  • Server welcoming event Personal Championship added
  • Gold costs for some Academy Tech upgrades removed
  • Territory Protection added to Alliance Tech
  • Castle level after 15 are not caped by stage levels
  • Some castle skins removed (e.g. Halloween, Valentine, Easter)
X350s
  • Beginner event Imperial Treasure I gives 0 VIP points
  • Beta: heroes have multi-color star promotion
  • Beta: heroes in tower defense and heroes in world marches can be different
  • Beta: 4 hero towers and 4 unit towers in stages
  • Gem quests added to Bounty Hall
  • Some castle skins removed (e.g. Elf, Goblin Lab)
C400s
  • Beginner event Imperial Treasure I gives 60 VIP points
  • Gem quests added to Bounty Hall
