In Kingdom Guard, servers are grouped into various groups.

Official Grouping

Servers are grouped into four clusters

  • S1: 9001 ~ S024
  • S2: 401 ~ 1150, 2002
  • S3: 1151 ~ 1598
  • S4: 1599 ~

Unofficial Grouping

The following is an unofficial description of the server clusters. A different naming scheme is used in order to captivate the complexity of the actual mechanism.

Servers are grouped into several Main Clusters, which are further divided into Sub Clusters. In general, servers in the Main Cluster play the same system.

Cross-Server Matching

The following are based on Main Clusters

  • Dimensional Tunnel
  • Dimensional Tunnel Cross-Server Leaderboard
  • Lave Cave Leaderboard
  • Evil Spirit Invasion Leaderboard
  • Ultimate Power Leaderboard
  • Ultimate Hunting Leaderboard
  • Wishing Pool in special events
  • Cross-Server Leaderboard in special events

The following are based on Sub Clusters

  • Releases of new heroes and tiers
  • Cross-Server Invasion matching
  • Mightiest Kingdom matching
  • Burning Expedition matching
  • Personal Server transfer and cross-server summoning
  • Alliance Cross-Server Summon
