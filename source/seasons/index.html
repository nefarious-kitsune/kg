Server Phases

Every server goes through several Phases.

Pre-Season Phase

Pre-Season Phase starts with the Great Fog and leads up to the Throne War. At the end of the Throne War, a King/Queen will be selected.

Seasonal Phase

Seasonal Phase (SvS/KvK Phase) include all cross-server events (e.g. Cross-Server Invasion, Battle of the Dragon, and Burning Expedition). All events occur in a 28-day cycle called Season.
