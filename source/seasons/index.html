Server Phases

Every server goes through several Phases.

  • Phase 1 starts with the Great Fog and leads up to the Sentry War.
  • Phase 2 leads up to the Throne War. At the end of the Throne War, a King/Queen will be selected.
  • Transition Phase (SvS Phase) includes some cross-server events and leads up to the first Server Transfer week. (See Transition Calendar)
  • Phase 3 (KvK Phase) include all cross-server events (e.g. Cross-Server Invasion, Battle of the Dragon, and Burning Expedition). All events occur in a 28-day cycle called Season. (See Phase 3 Calendar)
