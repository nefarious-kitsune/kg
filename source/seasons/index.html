Server Phases

Every server goes through several Phases.

Phase 1

Phase 1 starts with the Great Fog and leads up to the Sentry War.

Phase 2

Phase 2 leads up to the Throne War. At the end of the Throne War, a King/Queen will be selected.

Transition Phase

Before a server enters Phase 3, there is a Transition Phase which is either 1-week, 2-week, or 3-week long. In this period, the server will have some cross-server events.

Phase 3 and KvK Seasons

Phase 3 (SvS/KvK Phase) include all cross-server events (e.g. Cross-Server Invasion, Battle of the Dragon, and Burning Expedition). All events occur in a 28-day cycle called Season.
