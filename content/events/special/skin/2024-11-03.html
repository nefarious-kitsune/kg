Event Rewards

In this event, Lords have a chance to obtain the following rewards.

  • Green
  • Winter Grain Stockpile Frame
  • Bountiful Harvest Castle
  • Winter Warmth Barn Castle

Event Format

Chest Collection

Search for chest locations and dispatch troops to collect chests. For every 4 chests collected, receive a Grain Storage Bag.

Grain Storage Pass

Consume Grain Storage Bag earned from Chest Collection to unlock Event Pass rewards for Gold Action Points:

  • Free-tier: 500 Gold Action Points
  • Paid-tier: 1350 Gold Action Points and 1 permanent Avatar Frame
Winter Grain Daily Record

Complete five-day login quests rewards for Gold Action Points.

See 5-Day Login Quests.

Lucky Wheel

Consume Gold Action Points (collected from Event Pass, Quests, Wishing Pool, and event pack purchases) to draw rewards from the event treasure vault. Tap the upper-right button to switch between the Normal Mode and the Crazy Mode.

Winter Blessing Pool

Consume Gems to make a wish at the Wishing Pool and receive rewards. The first 100 wishes made daily will grant a Gold Action Points.

Half of all gems used will be added to the grand prize, and one lucky Lord will be randomly selected to win the grand prize.
